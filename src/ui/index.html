Wake On LAN
Wake On LAN lets you power on this device remotely from another HopToDesk client or the dashboard.
Requirements:
• This device must be connected via Ethernet (not WiFi)
• WoL must be enabled in the device's BIOS/UEFI settings
• The network adapter must have WoL enabled in OS settings
• Another HopToDesk device on the same network must be online to relay the wake signal
The wake signal is sent by another online HopToDesk device on the same local network.
